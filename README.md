# Feather Design website

Draft homepage for Feather Design, shared for feedback.

- `index.html` is the whole page: HTML, CSS, JavaScript and the intro animation in one file. It loads fonts from Google Fonts and nothing else.
- The site is published with GitHub Pages from the `main` branch.
- Project names, imagery, client logos, product names and the contact email are placeholders. The "Draft" button at the bottom left of the page lists them.
