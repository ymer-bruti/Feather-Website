# Feather Design website

Draft homepage for Feather Design, shared for feedback.

- `index.html` is the homepage: HTML, CSS, JavaScript and the intro animation in one file.
- `case-study.html` is the case study template. The project comes from the link, for example `case-study.html#lumen`; project content lives in the `CASES` list near the bottom of the file.
- Both pages load fonts from Google Fonts and nothing else. The footer is identical on every page.
- The site is published with GitHub Pages from the `main` branch.
- Project names, imagery, client logos, product names and the contact email are placeholders. The "Draft" button at the bottom left of the page lists them.
